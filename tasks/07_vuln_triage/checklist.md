# 脆弱性脅威度調査 チェックリスト

- [ ] 対象CVE・影響バージョン・修正バージョンを一次情報（ベンダー公式・NVD・JVN等）で確認したか
- [ ] CVSSだけでなく、悪用実態（KEV・PoC有無等）と対象環境の露出・緩和策を踏まえて評価したか
- [ ] 確認済み事実と未確認事項（現場確認が必要な資産・設定情報）が明確に分離されているか
- [ ] 恒久対策と暫定緩和策の両面が提示されているか
- [ ] 自社固有の機密構成情報や未公開脆弱性情報を外部検索等へ漏洩させていないか
- [ ] 透明性レポート（`reports/transparency_report.md`）へ初回要求と修正履歴を反映したか
