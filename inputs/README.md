# 共通資料投入トレイ（`v2/inputs/`）

今回AIに読み込ませたい資料（PDF・Word・Excel・テキスト・画像など）を、**まずここへ配置**してください。

## 使い方
1. 今回読ませたいファイルだけを本フォルダ（`v2/inputs/`）へドラッグ＆ドロップする。
2. AIへ「この資料で提案書を作って」「この前の〇〇案件を再開して、新しい資料を取り込んで」と依頼する。
3. AIがファイル一覧と参照範囲（この資料のみ／外部検索併用）を選択式UIで確認する。
4. 承認後、資料は対象案件の `v2/projects/<案件名>/inputs/` へ自動移動され、**本フォルダは空（`README.md` のみ）へ戻ります**。

> ※ 本 `README.md` はフォルダ保持用のため削除しないでください（自動移動の対象外です）。
