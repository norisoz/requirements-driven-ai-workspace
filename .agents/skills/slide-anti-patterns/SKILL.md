# slide-anti-patterns（AIスライドで避けるべき要素集）

## 適用対象
- 対象タスク：`v2/tasks/01_slides/`（資料作成）
- 適用工程：**作成工程**（レイアウト・文面生成時）および **レビュー工程**（提出前点検時）

## 避けるべき要素（NG）と改善ルール（OK）

| カテゴリ | 避けるべき要素（NG） | 改善ルール（OK） |
|---|---|---|
| メッセージ設計 | **1スライド全部盛り**：共有事項・論点・手順・リスク・判断事項を1枚に詰め込む | **1スライド1メッセージ**を徹底する。共有スライドと判断依頼スライドを分離する |
| タイトル・論点 | 「論点：〜」と題しながら論点（意思決定の問い）になっていない | タイトルまたは上部リード文に「何を決めるか／結論は何か」を1文で言い切る |
| 装飾の乱用 | 意味のない**左縦棒（アクセントバー）**、**カギカッコ「」**の多用、意味のない**水平仕切り線** | 装飾は最小限にする。強調は太字や配置・余白で行い、無意味な記号や線を描かない |
| ナンバリング・矢印 | `01`, `02`, `03` のようなゼロ埋め連番と台切り（シェブロン）矢印の安易な多用 | 順序が必要な場合のみ簡潔な番号（1, 2, 3）を用い、装飾的なシェブロン矢印を乱用しない |
| テキストの冗長性 | 見出し下に長文の補足文をぶら下げる／下段と重複する小見出しを書く | 見出しだけで意味が伝わる表現に磨き、重複するリード文や補足説明を削る |
| 反復見出しの重複 | 横並びカードすべてに「リスク」「ご判断いただきたい点」と同じラベルを毎回繰り返す | 共通の観点ラベルは左端に1回だけくくり出し（マトリクス化）、各列は中身だけを書く |
| 配色の意味崩壊 | 3列のうち1列だけ根拠なくグレーにする等、意味のない色変更で対比構造を壊す | 色は意味（強調・ポジティブ/ネガティブ・分類）と1対1で対応させ、装飾目的で変えない |
| レイアウト・余白 | 特定ボックスだけ高さが伸びる、下端や左右余白が不揃いになる | グリッド・上端/下端・余白幅を厳密に揃え、視覚的なガタつきをなくす |
| 改行位置 | 「〜部 / 門か」「〜状 / 況による」など、単語の途中で不自然に改行される | 文節・単語の区切りで折り返されるよう文字量またはボックス幅を調整する |
| 注釈・免責事項 | スライド下部に極小文字で改行なしの長いAI定型免責文を詰め込む | 不要な定型免責文は削除する。必要な前提注記のみ1〜2行で簡潔に記す |

## レビュー時の確認手順
1. 1スライド内の要素数・目的が単一か確認する（共有と判断が混ざっていれば分割する）。
2. 無意味な装飾（左縦棒・カギカッコ・仕切り線・根拠のない色変更）を削除する。
3. 同一ラベルの繰り返しがあれば表形式（左見出し）へ整理する。
4. 全ボックスの上下左右の揃い・余白・単語途中の改行崩れを点検する。
5. 下部の極小文字の長文注釈が残っていれば削除または簡潔化する。
