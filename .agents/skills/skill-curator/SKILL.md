# skill-curator（知見・NG要素のスキル化およびタスク反映スキル）

## 目的
SNSで得たノウハウや、成果物レビューで見つかった「避けるべき要素（アンチパターン）」をその場で再利用可能なスキルへ昇華し、該当タスクのプロンプト・チェックリストへ安全に組み込む。

## 実行手順（厳守）

### ステップ1：知見・アンチパターンの構造化抽出
1. ユーザーから提供された画像・テキスト・URL・レビュー指摘を読み取る。
2. 内容を以下の形式で整理し、仮案として提示する。
   - **避けるべき要素（NGパターン）** と **その理由**
   - **推奨される代替ルール（OKパターン）**
   - **想定スキル名**（小文字ハイフン区切り、例：`slide-anti-patterns`）

### ステップ2：配置先・対象タスク・使用工程の選択式確認（人間承認①）
ファイルを作成する前に、必ず **Antigravity の選択式質問UI（`ask_question` 等）** を用いて以下3点を人間へ確認する。
1. **スキルの配置先**:
   - チーム共通：`v2/.agents/skills/<スキル名>/SKILL.md`
   - 個人専用：`~/.gemini/config/skills/<スキル名>/SKILL.md`
   - 既存スキルへの追記（該当スキル名を選択肢化）
2. **反映先のタスク（複数選択可）**:
   - `v2/tasks/` 配下の該当タスク（例：`01_slides`、`02_proposals`、`03_programming`、`04_research`、`05_policies`、`06_minutes_notices`、`07_vuln_triage`）
3. **対象タスクでの使用工程（複数選択可）**:
   - 設計・構成検討工程（骨子・構成案作成時）
   - 作成・生成工程（本文・スライド・コード生成時）
   - レビュー・チェック工程（提出前の自己点検・チェックリスト照合時）

### ステップ3：作業計画（7項目）の提示と選択式承認（人間承認②）
- `v2/core/AGENTS.md` に従い、7項目の作業計画（新規 `SKILL.md` の構成、対象タスクの `prompt.md`・`checklist.md` への反映内容、影響範囲、ロールバック方法）を提示する。
- **選択式UI** で「承認して実行する／修正する」の承認を取得する。

### ステップ4：スキル作成とタスクへの反映
承認後、以下を実行する。
1. 指定された配置先へ `SKILL.md`（YAML frontmatter の `name` / `description` 必須）を作成または更新する。
2. 対象タスクの `v2/tasks/<タスク>/prompt.md` にある「使用するSkills（工程別）」表へ、スキル名・適用工程・目的を追記する。
3. 「レビュー・チェック工程」が選択された場合、`v2/tasks/<タスク>/checklist.md` へ対応する確認項目を追記する。
4. チーム共通スキルの場合は `v2/.agents/skills/README.md` の一覧へ追記する。

## 禁止事項
- コア6スキル（`mission-intake` 等）および `v2/core/AGENTS.md` の安全・承認制約を上書き・緩和しない。
- 人間の選択・承認を経ずに、勝手にタスクフォルダや既存スキルを書き換えない。
- 選択式UIが利用可能な環境で、自由記述テキストのみで分岐や承認を求めない。
